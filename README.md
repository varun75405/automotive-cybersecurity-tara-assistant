# Automotive Cybersecurity TARA Assistant

An AI-assisted Threat Analysis and Risk Assessment (TARA) platform for automotive systems and security engineers, aligning with **ISO/SAE 21434:2021** and **UNECE R155** principles.

---

## 📌 Repository Structure
This repository follows the standardized Capstone folder structure:
- **`Synopsis/`**: Project overview, architectural objectives, and high-level scope.
- **`Input_Data/`**: Knowledge base documents (Sample vehicle architecture, communication matrix, ECU inventory, automotive threat library, attack surface catalog, mitigation library, and evaluation questions).
- **`Code/`**: Source code for the backend (FastAPI), frontend (Streamlit), RAG pipeline, TARA engine, and automated test suite.
- **`Model_Prompts_Config/`**: System prompts, configuration schemas, and environment template.
- **`Evaluation_Results/`**: Benchmark evaluation results (`evaluation_summary.json`, `ui_eval_out.json`) and full pytest test suite execution logs (`pytest_results.txt`).
- **`Documentation/`**: Technical report, system architecture, RAG pipeline design, demo script, and responsible AI documentation.
- **`Video/`**: Demonstration video link and walkthrough notes.
- **`Declarations/`**: Academic integrity and AI tool usage declarations.

## 🚀 Quick Setup & Execution

### 1. Prerequisites
- Python 3.10+ (tested with Python 3.13)
- Git

### 2. Installation
Navigate into the `Code/` directory and install dependencies:
```bash
cd Code
pip install -r requirements.txt
```

### 3. Environment Configuration
Copy the template configuration file:
```bash
cp .env.example .env
```
Edit `.env` to configure your preferred LLM provider:
- **Demo Fallback Mode**: `LLM_PROVIDER=demo` (Requires NO API keys; operates completely offline with deterministic automotive data).
- **Google Gemini**: `LLM_PROVIDER=gemini`, set `GEMINI_API_KEY=<your_key>`, and `GEMINI_MODEL=gemini-3.8-flash`.

### 4. Running the Streamlit Application
```bash
streamlit run frontend/streamlit_app.py
```

### 5. Running the Automated Test Suite
From the `Code/` directory:
```bash
python -m pytest -q
```
*(All 73 unit and integration tests execute with 100% pass rate).*

## 🛡️ Demo-Fallback Mode Behavior
The platform features an enterprise-grade **Demo Fallback Mode**:
- **Automatic Fallback on Quota Exhaustion**: If Gemini returns HTTP 429 (Resource Exhausted) or transient errors exhaust retries, the system transparently shifts to predefined deterministic automotive cybersecurity data.
- **Extractive Q&A**: The RAG assistant extracts answers directly from uploaded specifications (e.g. `RAG_Test_Battery_Monitoring_Spec.pdf`) using keyword overlap and sentence deduplication without hallucinating facts.
- **Transparent Provenance**: UI badges prominently display `DEMO FALLBACK (Predefined Data)` so users are always aware of data origin.

## ⚠️ Limitations & Qualified Engineering Review
- **Candidate Findings Only**: All asset identifications, threat scenarios, impact scores, and mitigations generated by this tool are engineering candidates.
- **Human-in-the-Loop Required**: Qualified automotive cybersecurity engineers must formally review, edit, accept, or reject every finding.
- **No Direct Compliance Claims**: Use of this tool does not automatically certify compliance with ISO/SAE 21434 or UNECE R155.
