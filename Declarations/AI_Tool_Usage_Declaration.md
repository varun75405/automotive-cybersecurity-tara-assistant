## Guiding Principles & Verification Responsibilities

1. **Human Oversight:** AI-assisted code, mathematical risk formulas, and report sections were inspected, understood, and tested using the automated test suite before submission.
2. **Deterministic Guardrails:** Quantitative risk scoring ($\text{Risk Score} = \text{Impact Score} \times \text{Feasibility Score}$) is computed via deterministic Python logic rather than LLM generation to prevent hallucinations.
3. **Viva Defense Readiness:** The student can explain every major component, architectural layer, vector chunking strategy, prompt guardrail, and evaluation metric during viva voce examination.
4. **Advisory Tagging:** Every candidate cybersecurity requirement generated by the system explicitly includes the disclaimer:  
   `"AI-generated candidate requirement — requires cybersecurity engineer approval."`
